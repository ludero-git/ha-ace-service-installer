# ACE Service Installer

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Install and run the Alfen ACE Service Installer in Home Assistant.

Supports AMD64 using Wine and ARM64 using Hangover.

See the [**Documentation**](./documentation) tab for usage and troubleshooting.
